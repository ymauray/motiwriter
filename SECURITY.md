# Politique de sécurité

## Versions supportées

| Version | Supportée |
| --- | --- |
| `main` / dernière [release](https://github.com/ymauray/motiwriter/releases/latest) | :white_check_mark: |
| Anciennes versions | :x: |

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique.**

Utilisez le signalement privé de vulnérabilité de GitHub : onglet
[Security](https://github.com/ymauray/motiwriter/security), puis **Report a vulnerability**.

Décrivez le problème, les étapes pour le reproduire et son impact potentiel (par exemple : accès
aux jours d'un autre compte, contournement de la connexion, fuite d'un secret). Le signalement sera
examiné dans les meilleurs délais, et un correctif sera publié avant toute divulgation publique.
